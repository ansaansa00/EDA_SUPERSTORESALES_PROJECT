# EDA_SUPERSTORESALES_PROJECT
#  Project Description
This project focuses on performing Exploratory Data Analysis (EDA) on the Superstore dataset to understand sales performance, customer purchasing behavior, profitability trends, and regional business performance. 
The dataset contains retail transaction information such as customer details, product categories, shipping methods, sales values, discounts, and profit generated from each order.
The project aims to analyze business operations using statistical methods and data visualization techniques to identify meaningful patterns, trends, and insights. 
By studying different aspects of the dataset, the analysis helps understand how factors such as discounts, product categories, customer segments, and regions affect overall business performance.
